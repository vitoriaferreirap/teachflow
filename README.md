# Plataforma para Professores de Inglês

Plataforma web que começa como **portfólio de uma professora de inglês** e evolui
para uma ferramenta de gestão do seu microempreendimento: aulas, pagamentos e
venda de cursos recorrentes.

## Objetivos

- **Fase 1 – Portfólio:** apresentar a professora, seus métodos, materiais e resultados.
- **Fase 2 – Gestão:** agendar aulas e acompanhar alunos.
- **Fase 3 – Receita recorrente:** cobrar mensalidades e vender cursos online.
## Técnologias:
- Baanco: Sequelize e PostgreSQL
- Frontend: Html, Rect.js, JavaScript
- Beckend: NodeJS, Express, JavaScript
- Infra: Docker, Docker compose

## Transmissão dados servidor - API:
- A comunicação entre frontend e backend é feita via HTTP, seguindo o padrão REST (GET/ POST/ PUT / PATCH/ DELETE)
